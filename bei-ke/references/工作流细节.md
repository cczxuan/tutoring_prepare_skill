# 备课工作流 · 详细操作指南

## Step 1 · 制定15天周期方案

### 执行步骤

1. 读取 `基本档案.txt`，确认学生画像
2. 分析核心问题（分数低的主因：基础词汇？语法体系？语感？）
3. 划分三阶段：
   - 第一阶段（约前半周期）：教材基础语法重建，对应教材模块
   - 第二阶段（中间段）：能力提升（阅读、写作、听力）
   - 第三阶段（末尾）：下一年级/下一单元衔接预览
4. 逐日填写内容，每节课标注：对应教材模块、时间分配、语法点、话题词汇、输出活动
5. 在周期中间设置阶段测验（如Day 7），作为进度调整分水岭
6. 添加配套安排（课后任务、教学提醒）

### 检查项

- [ ] 内容量是否适合该分数段（35分的学生宁可少教，确保教会）
- [ ] 语法点是否螺旋式重复（不在一个课时讲完就丢）
- [ ] 每节课是否有输出环节（不只是输入）
- [ ] 阶段测验有备用方案（如测验不及格，后续计划如何调整）

### 指令模板

```
读取基本档案，制定15天学习方案，使用外研版教材，每天一次
```

## Step 2 · 撰写单日教案

### 执行步骤

1. 从周期方案中摘取当天的教学内容
2. 如果前一天有复盘，根据复盘调整当天内容和难度
3. 根据学生基础水平做减法——只保留最核心的知识点
4. 按2小时（120分钟）分配时间块，每块20-40分钟
5. 每个时间块按"引入 → 讲解 → 操练 → 输出"结构组织
6. 包含以下章节：教学目标、教学流程、板书设计、课后任务、课后反思问卷

### 原则

- 基础弱的学生：一次只教1-2个核心语法点，不贪多
- 每15-20分钟切换活动形式（讲→练→说→写），维持注意力
- 课后任务量控制在"10分钟能搞定"，否则基础差的学生不做
- 第一节课的目标是"让学生愿意明天继续来"，不是学会多少

### 指令模板

```
根据15天方案中的Day{N}内容，撰写教案，对象基础薄弱，内容不宜多
```

## Step 3 · 制作PPT课件

### 前置条件

guizang-ppt-skill 已安装在 `~/.codex/skills/guizang-ppt-skill/`。

### 风格选择

- 家教课件推荐 瑞士国际主义风（Style B）
- 主题色推荐 克莱因蓝（IKB）
- 版式多样性：7-8页至少用6种不同版式

### 典型版式分配（7页为例）

| 页码 | 版式 | 内容 |
|------|------|------|
| 01/07 | S01 Cover（IKB满屏+ASCII呼吸场） | 封面标题 |
| 02/07 | S19 Four Cards（4列均分卡） | 口诀/规则并列 |
| 03/07 | S04 Six Cells（12列网格） | 对照表 |
| 04/07 | S16 Brief Cards（3x2微卡） | 练习 |
| 05/07 | S03 Statement（左右分屏） | 老师示范 vs 学生模板 |
| 06/07 | S13 Three Forces（3列对等卡） | 3步流程 |
| 07/07 | S10 Split Closing（IKB+白底收束） | 总结+课后任务 |

### 操作流程

1. 从 skill 中 copy template-swiss.html 到 `ppt/index.html`
2. 替换 `<title>[必填]...</title>` 为实际标题
3. 替换 `<!-- SLIDES_HERE -->` 区块为 slide 代码段
4. 每页 slide 结构：
   ```html
   <section class="slide {light|accent|split}" data-animate="{recipe名}" data-layout="{Sxx}">
     <div class="canvas-card">
       <div class="chrome-min">
         <div class="l">SECTION · NAME</div>
         <div class="r">NN / 07</div>
       </div>
       <div style="flex:1;padding:0;display:grid;...">内容</div>
     </div>
   </section>
   ```

### 检查项

- [ ] 标题占位符 [必填] 是否全部替换
- [ ] slide 是否在 `<div id="deck">` ... `</div>` 内部
- [ ] 中文标题字号按长度降级（8字内用合适字号）
- [ ] 不要使用内置图片生成工具生成配图

### 指令模板

```
结合ppt skill，将教案中的核心教学内容做成PPT，风格用瑞士风，不用生成图片
```

## Step 4 · 课后复盘

### 执行步骤（课后5分钟填写）

1. 掌握度评估：打3个勾
   - 学生能独立说出/写出今天学的核心句型？
   - 学生能独立做完课堂练习（正确率 >= 60%）？
   - 学生走的时候状态是积极的？

2. 计划调整判断
   - 正确率 < 40% → 明天暂停新课，重复今天内容
   - 正确率 60-80% → 按原计划推进
   - 正确率 > 80% → 适当加快，增加拓展内容

3. 记录具体问题：最卡壳的点？什么方法反应好？明天需要复习什么？

4. 更新周期方案（如果需要）：在 `15天学习方案.md` 中标注改动

### 产出格式

```
# Day {N} 复盘

## 掌握度
- [ ] 能独立输出核心句型
- [ ] 练习正确率 >= 60%
- [ ] 状态积极

## 调整判断
[加速 / 原计划 / 减速重复]

## 记录
- 卡壳点：
- 好方法：
- 明天课前复习：
```
