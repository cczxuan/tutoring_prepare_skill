# 备课工作流 · 详细操作指南

## Step 0 · 需求确认（必做）

动手前先确认以下信息。如果用户没说，**先问**。

### 必问清单

| 问题 | 为什么问 |
|------|---------|
| 什么科目？教材版本？ | 不默认英语。不同科目备课逻辑不同 |
| 学生当前水平？ | 决定内容难度和节奏 |
| 课时长度？ | 决定教案的时间分配。默认2小时 |
| **长期规划还是单次备课？** | 决定走路径A还是路径B |
| 如果是长期：周期多长？上课频率？ | 决定方案长度。不默认15天 |

### 不需要问的

- 用户说"制定暑假方案" → 这就是长期规划，问周期长度即可
- 用户说"帮我准备明天的课" → 这就是单次备课，走路径B
- 用户直接给了完整信息 → 直接执行，不需要重复确认

---

## 路径A · 长期规划

### 执行步骤

1. 确认周期长度和上课频率（用户决定，不硬编码）
2. 确认科目和教材版本
3. 根据科目类型选择阶段划分策略：
   - **语言类**（英语/语文）：基础重建 → 阅读写作提升 → 新学期衔接
   - **理科类**（数学/物理）：概念重建 → 题型训练 → 新学期预习
   - **其他**：按科目内容逻辑分段
4. 逐次填充内容，每节课标注：教材模块、知识点、时间分配、输出活动
5. 在周期中设置阶段测验/节点，作为进度调整分水岭
6. 产出：`{名称}学习方案.md`（不强制叫"15天"）

### 检查项

- [ ] 内容量是否匹配学生水平（基础弱的学生宁可少教）
- [ ] 知识点是否螺旋式重复
- [ ] 每节课是否有输出环节
- [ ] 阶段测验有备用方案

### 指令模板

```
根据学生情况制定学习方案，[科目]，[周期长度]，[上课频率]
示例：制定一个暑假英语学习方案，外研版，两个月每周两次
```

---

## 路径B · 单次备课

### 执行步骤

1. 确认科目、课题、学生水平
2. 直接撰写教案，不涉及周期方案
3. 产出：`{课题}教案.md` 或 `Day{N}教案.md`

### 什么时候走B

- 用户只提了一节课的内容
- 用户说"帮我备课"但没有提长期安排
- 用户明确说"就一次课"

### 指令模板

```
帮我准备明天的课，[科目]，[课题]，[学生水平]
示例：帮我准备明天的小学数学课，人教版三年级，分数初步认识
```

---

## 共享步骤 · 撰写教案

### 教案结构

1. **基本信息**：科目、教材版本、课题、预计用时
2. **教学目标**：2-4条，可衡量（如"能正确使用...""能独立完成..."）
3. **教学流程**：
   - 按时间块组织，每块20-40分钟
   - 每块结构：引入 → 讲解 → 操练 → 输出
   - 标注每个环节的用时
4. **板书/可视化设计**
5. **课后任务**（控制在10-15分钟）
6. **课后反思问卷**（教师自填，几个勾选问题）

### 原则

- 基础弱的学生：一次只教1-2个核心知识点
- 每15-20分钟切换活动形式（讲→练→说→写）
- 课后任务量控制在"10-15分钟能搞定"

## 共享步骤 · 制作PPT课件

### 前置条件

guizang-ppt-skill 已安装在 `~/.codex/skills/guizang-ppt-skill/`

### 风格选择

| 课件类型 | 推荐风格 | 推荐主题色 |
|---------|---------|-----------|
| 常规课件（语法/公式/概念） | 瑞士风（Style B） | 克莱因蓝 |
| 人文类（语文/历史/故事） | 电子杂志风（Style A） | 墨水经典 |
| 理科类（物理/数学/图表） | 瑞士风（Style B） | 克莱因蓝或安全橙 |

### 典型页数

5-8页。长期方案中的一节课和单次备课的处理方式相同。

### 操作流程

1. copy template（瑞士风）或 template-swiss.html → `ppt/index.html`
2. 改 `<title>` 占位符
3. 替换 `<!-- SLIDES_HERE -->` 为 slide 代码段
4. 每页 slide 结构：
   ```html
   <section class="slide {light|accent|split}" data-animate="{recipe}" data-layout="{Sxx}">
     <div class="canvas-card">
       <div class="chrome-min">...</div>
       <div style="flex:1;padding:0;display:grid;...">内容</div>
     </div>
   </section>
   ```

### 检查项

- [ ] 标题占位符 [必填] 是否全部替换
- [ ] slide 在 `<div id="deck">` ... `</div>` 内部
- [ ] 中文标题字号按长度降级
- [ ] 不要使用内置图片生成工具生成配图

### 指令模板

```
结合ppt skill，把教案内容做成PPT，不用生成图片
```

## 共享步骤 · 课后复盘

### 执行步骤（课后5分钟）

1. 掌握度评估：3个勾
   - 学生能独立输出核心内容？
   - 练习正确率 >= 60%？
   - 状态积极？

2. 调整判断
   - 正确率 < 40% → 重复今天内容
   - 60-80% → 按计划推进
   - > 80% → 加快进度

3. 记录具体问题
   - 最卡壳的点是什么？
   - 什么方法学生反应好？
   - 明天需要复习什么？

### 产出格式

```
# Day {N} 复盘

## 掌握度
- [ ] 能独立输出核心内容
- [ ] 练习正确率 >= 60%
- [ ] 状态积极

## 调整判断
[加速 / 原计划 / 减速重复]

## 记录
- 卡壳点：
- 好方法：
- 下次课前复习：
```
