# 备课工作流（Bei Ke）

家教备课四步闭环：**制定周期方案 → 撰写教案 → 制作PPT → 课后复盘**

## 工作流概览

### 四步闭环

| 步骤 | 产出 | 一句话 |
|------|------|--------|
| Step 1 · 周期方案 | `15天学习方案.md` | 根据学生档案和教材版本，规划15天的学习节奏 |
| Step 2 · 单日教案 | `Day{N}教案.md` | 从周期方案摘取当日内容，写出详细的2小时授课流程 |
| Step 3 · PPT课件 | `ppt/index.html` | 用 guizang-ppt-skill 将教案核心内容做成横向翻页网页 |
| Step 4 · 课后复盘 | `Day{N}复盘.md` | 记录学生掌握度，判断明天是否需要调整进度 |

**关键原则**：复盘结果直接输入第二天的教案，形成动态调整闭环。详细流程见 `references/工作流细节.md`。

## 执行指南

### 前提假设

- 学生档案在 `基本档案.txt` 中（含年龄、年级、科目、当前水平、教材版本、上课频率）
- 所有产出文件放在 workspace 根目录下

### Step 1 · 制定15天周期方案

**向用户确认**：教材版本（如外研版/人教版）、上课频率（每天/隔天）、每节课时长

**内容结构**：
- 划分三阶段：基础重建 → 能力提升 → 下一年级衔接
- 逐日标注：对应教材模块、时间分配、语法点、词汇、输出活动
- 在周期中间设置阶段测验作为进度调整分水岭

**产出格式**：`15天学习方案.md`，按天排列，每节课2-3行概要

### Step 2 · 撰写单日教案

**输入**：
- 周期方案中当天的概要
- 前一天的复盘文件（如有）

**内容结构**（用 `Day{N}教案.md` 输出）：
1. 教学目标（3-4条，可衡量）
2. 教学流程（分Step，每步标注用时）
3. 板书设计
4. 课后任务（15-20分钟可完成）
5. 课后反思问卷（教师课后自填）

**原则**：基础弱的学生一次只教1-2个核心语法点，每15-20分钟切换活动形式。

### Step 3 · 制作PPT课件

**前置条件**：已安装 `guizang-ppt-skill`（位于 `~/.codex/skills/guizang-ppt-skill/`）

**风格选择**：
- 家教课件推荐 **瑞士国际主义风（Style B）**：干净、结构化
- 主题色推荐 **克莱因蓝（IKB）**：冷静理性，适合教学

**典型页数**：7页（Cover → 口诀 → 对照表 → 练习 → 示范 → 3步走 → 总结），7-8页至少用6种不同版式。

**操作流程**：
1. copy template-swiss.html → `ppt/index.html`
2. 改 `<title>` 占位符
3. 替换 `<!-- SLIDES_HERE -->` 为 slide 代码段
4. 每页 slide 使用 `.canvas-card` + `.chrome-min` + grid 内容区结构

**注意**：不要使用内置图片生成工具（imagegen）生成配图，保持纯文字排版。

### Step 4 · 课后复盘

**执行时机**：下课后5分钟内填写 `Day{N}复盘.md`

**核心问题**：
1. 学生能独立输出核心句型吗？
2. 明天该加速、减速还是原地重复？
3. 今天最卡壳的点是什么？什么方法学生反应好？

**调整规则**：
- 正确率 < 40% → 明天重复今天内容
- 正确率 60-80% → 按原计划推进
- 正确率 > 80% → 加快进度，增加拓展

## 指令模板

### 启动周期方案
```
读取基本档案，制定15天学习方案，使用外研版教材，每天一次
```

### 撰写教案
```
根据15天方案中的Day{N}内容，撰写教案，对象基础薄弱，内容不宜多
```

### 制作PPT
```
结合ppt skill，将教案中的核心教学内容做成PPT，风格用瑞士风，不用生成图片
```

### 课后复盘
略——人工操作，5分钟填完
