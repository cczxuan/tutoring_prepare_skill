# 备课工作流（Bei Ke）

备课四步闭环：**了解需求 → 方案/教案 → 课件 → 复盘**

## 适用场景

- **长期规划**：暑假/学期系统补习，需要制定周期方案 > 逐日写教案
- **单次备课**：明天有一节课需要准备，直接写教案做课件，不需要周期方案

两种路径在"方案/教案"处分叉，后续步骤共享。

## 工作流

### Step 0 · 需求确认（必做）

动手前先确认以下信息，不要假设：

| 问题 | 用途 |
|------|------|
| 什么科目？教材版本？ | 决定内容方向。不要默认是英语 |
| 学生当前水平？ | 决定内容难度和节奏 |
| 课时长度？ | 决定教案的时间分配（默认2小时） |
| **长期规划还是单次备课？** | 决定走哪条路径 |
| 如果是长期：周期多长？上课频率？ | 决定方案的总长度和内容密度 |

如果用户没说，先问。如果用户给了模糊信息，用合理默认值推进并在回复中说明。

### 路径A · 长期规划

```
用户需求 → 确定周期长度（可配，不默认15天）
       ↓
       ↓ 划分阶段（基础重建 → 能力提升 → 衔接预览）
       ↓ 逐日填充内容（标注教材模块、用时分配、知识点）
       ↓
   周期方案.md
       ↓
（进入路径B的教案撰写步骤）
```

**周期长度由用户决定**，不要硬编码15天。例如：
- 用户说"暑假两个月每周两次" → 16次课的方案
- 用户说"期末考前两周冲刺" → 14天方案
- 用户没说 → 问：""你大概想规划多长的周期？""

**阶段划分策略根据科目调整**：
- 语言类（英语/语文）：基础知识重建 → 阅读写作提升 → 新学期衔接
- 理科类（数学/物理）：概念重建 → 题型训练 → 新学期预习
- 其他科目按实际内容逻辑分段

### 路径B · 单次备课

```
用户需求 → 直接撰写教案（单次，无周期方案）
       ↓
   教案.md
       ↓
（进入后续步骤）
```

**什么时候走B**：
- 用户只提到了某一节课，没有提长期规划
- 用户说"帮我准备明天的课"
- 用户说"写一份关于XX的教案"

### 共享步骤

#### 撰写教案

**内容结构**（`Day{N}教案.md`）：

1. **基本信息**：科目、教材版本、课题、预计用时
2. **教学目标**：2-4条，可衡量
3. **教学流程**：按时间块组织，每块含引入→讲解→操练→输出
4. **板书/可视化设计**
5. **课后任务**（如有）
6. **课后反思问卷**（教师课后自填）

**原则**：
- 基础弱的学生：一次只教1-2个核心知识点，不贪多
- 每15-20分钟切换活动形式
- 课后任务控制在10-15分钟可完成

#### 制作PPT课件

**前置条件**：已安装 `guizang-ppt-skill`

**风格推荐**：
- 常规课件：瑞士国际主义风（Style B），克莱因蓝主题
- 人文类课件：电子杂志风（Style A）

**典型页数**：5-8页，视内容量调整。版式多样性规则：7-8页至少用6种不同S编号版式。

**操作流程**：
1. copy template-swiss.html → `ppt/index.html`
2. 改 `<title>` 占位符
3. 替换 `<!-- SLIDES_HERE -->` 为 slide 代码段
4. 不要使用内置图片生成工具生成配图

#### 课后复盘

**执行时机**：下课后5分钟内

**核心问题**：
1. 学生掌握度如何？（能独立输出核心内容吗？正确率？）
2. 明天该加速、减速还是原地重复？
3. 今天最卡壳的点是什么？什么方法学生反应好？

**记录格式**（`Day{N}复盘.md`）：
```
# Day {N} 复盘

## 掌握度
- [ ] 能独立输出核心内容
- [ ] 练习正确率 >= 60%
- [ ] 状态积极

## 调整判断
[加速 / 原计划 / 减速重复]

## 记录
- 卡壳点：
- 好方法：
- 下次课前复习：
```

## 指令模板

### 长期规划启动
```
根据学生情况制定学习方案，[科目]，[周期长度]，[上课频率]
示例：制定一个暑假英语学习方案，外研版，两个月每周两次
```

### 单次备课启动
```
帮我准备明天的课，[科目]，[课题]，[学生水平]
示例：帮我准备明天的小学数学课，人教版三年级，分数初步认识
```

### 制作PPT
```
结合ppt skill，把教案内容做成PPT，不用生成图片
```
