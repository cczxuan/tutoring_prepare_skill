# 备课工作流（bei-ke）

通用备课的 Codex Skill：**了解需求 → 方案/教案 → 课件 → 复盘**。

> 不限于科目，不固定周期，支持长期规划和单次备课两种模式。

---

## 适用场景

| 场景 | 走哪条路 |
|------|---------|
| "制定一个暑假英语学习方案" | 路径A · 长期规划 |
| "帮我准备明天的数学课" | 路径B · 单次备课 |
| "物理期中复习计划" | 路径A · 长期规划 |
| "写份语文教案，《背影》第一课时" | 路径B · 单次备课 |

两种路径在"方案/教案"处分叉，后续的课件制作和课后复盘共享。

## 工作流

```
                    ┌─────────────────────────┐
                    │  Step 0 · 需求确认      │
                    │  科目？周期？单次还是长期？│
                    └──────┬──────────────────┘
                           │
              ┌────────────┴────────────┐
              ▼                         ▼
     路径A · 长期规划           路径B · 单次备课
     周期方案.md                 跳过周期方案
              │                         │
              └────────────┬────────────┘
                           ▼
                  共享 · 撰写教案
                    Day{N}教案.md
                           │
                           ▼
                  共享 · 制作PPT（可选）
                    ppt/index.html
                           │
                           ▼
                  共享 · 课后复盘
                    Day{N}复盘.md
                           │
                           ▼
                  结果反馈到下一次备课
```

### 四步说明

**Step 0 · 需求确认**
先问清楚：科目？教材版本？学生水平？课时长度？长期规划还是单次备课？**不默认英语，不默认15天。**

**路径A · 长期规划**
用户确定周期长度（如"两个月每周两次"），按阶段划分 → 逐次填充内容 → 中间设阶段测验。

**路径B · 单次备课**
跳过周期方案，直接写教案。适合"明天有一节课"的场景。

**共享 · 教案与课件**
教案包含基本信息、教学目标、流程、板书设计、课后任务。PPT使用 guizang-ppt-skill 生成，支持瑞士风和电子杂志风两种风格。

**共享 · 课后复盘**
课后5分钟填写掌握度评估，判断明天是否调整进度。

## 使用示例

### 长期规划
```
根据学生情况制定数学学习方案，人教版七年级，暑假8周每周3次
```

### 单次备课
```
帮我准备明天的语文课，部编版八年级，《苏州园林》第一课时，学生基础一般
```

### 制作PPT
```
结合ppt skill，把教案内容做成PPT，不用生成图片
```
