# 备课工作流（bei-ke）

家教备课的 Codex Skill：**制定15天周期方案 → 按日撰写教案 → 制作PPT课件 → 课后复盘调整**。

一套完整的备课四步闭环，专为一对一家教场景设计。

---

## 安装

### 方式一：全局安装（推荐）

```bash
git clone https://github.com/你的用户名/bei-ke-skill.git ~/.codex/skills/bei-ke-skill
```

### 方式二：项目本地使用

直接克隆或复制 `bei-ke/` 目录到你的项目根目录下，Codex 会自动发现。

## 工作流

```
学生档案（基本档案.txt）
        ↓
Step 1  制定15天周期方案  →  15天学习方案.md
        ↓
Step 2  撰写单日教案      →  Day{N}教案.md
        ↓
Step 3  制作PPT课件       →  ppt/index.html
        ↓
Step 4  课后复盘          →  Day{N}复盘.md
        ↓                    （结果反馈到下一课）
  回到 Step 2 · 进入下一天
```

### 四步说明

**Step 1 · 周期方案**
读取学生档案，根据教材版本（外研版/人教版等）和上课频率，划分三阶段：基础重建 → 能力提升 → 下一年级衔接。在周期中间设置阶段测验作为进度调整分水岭。

**Step 2 · 单日教案**
从周期方案中摘取当天内容，按2小时分配时间块，每块20-40分钟。针对基础薄弱的学生做减法——一次只教1-2个核心语法点，不贪多。

**Step 3 · PPT课件**
使用 guizang-ppt-skill 的瑞士国际主义风模板（克莱因蓝主题），将教案核心内容做成横向翻页网页PPT。7页覆盖：封面 → 口诀 → 对照表 → 练习 → 示范 → 3步走 → 总结。

**Step 4 · 课后复盘**
课后5分钟填写：学生掌握度评估 + 明天是否调整进度 + 具体问题记录。复盘结果直接输入第二天备课，形成动态调整闭环。

## 使用示例

### 启动15天周期
```
读取基本档案，制定15天学习方案，使用外研版教材，每天一次
```

### 写某一天的教案
```
根据15天方案中的Day 1内容，撰写教案，对象基础薄弱，内容不宜多
```

### 生成PPT课件
```
结合ppt skill，将教案中的核心教学内容做成PPT，风格用瑞士风，不用生成图片
```
